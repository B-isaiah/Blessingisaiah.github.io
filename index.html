About Me

I am a QA Engineer and API Security Tester with experience testing web, mobile and API applications.

My work combines software quality testing with application security. I design test cases, validate application behaviour, identify defects and test APIs for functional and security issues.

I am particularly interested in API security and how authentication, authorization, business logic and API design affect the security of modern applications.
